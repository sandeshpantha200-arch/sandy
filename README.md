# Horizon G.B.S. School Alumni

A responsive alumni-community website built with plain HTML, CSS, and JavaScript. No build step is required: open `index.html` in a browser.

## Included

- Responsive navigation and alumni directory with live search and field filters
- Sample profile dialogs, upcoming event cards, and local RSVP controls
- Alumni registration through the published Google Form
- Story submissions, newsletter signups, and event RSVPs saved in browser `localStorage`

## Run

Open `index.html` directly in a modern browser. The page uses remote Unsplash and Google Fonts assets, so an internet connection is needed for those visuals and fonts. The core layout and interactions do not require a server.

## Before launch

The alumni profiles, event dates, and event descriptions are illustrative sample content, not verified Horizon G.B.S. School records. Replace them with approved information. Alumni registration responses are collected in the Google account that owns the form. Story submissions, newsletter addresses, and RSVPs remain in the visitor's browser and are not shared with the school.
